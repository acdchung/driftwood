# Driftwood

A tiny cozy sailing & fishing game built with [three.js](https://threejs.org).

Sail between islands, fish at rippling spots, sell your catch at Trading Posts, collect messages in bottles, find the treasure, and hop off your boat to explore.

## Play locally

Open `index.html` in a browser. That's it — three.js and the font load from a CDN.

## Controls

- **Phone:** drag anywhere to sail or walk, tap the buttons to cast / hook / get out
- **Desktop:** WASD or arrow keys to move · Space to cast · E to interact · J journal · M chart · B shop

## Deploy

It's a static site, so any static host works. On Vercel, import this repo with the default settings (no build step).
